# `src/tools/`

Reservierter Ordner für **Typen und Metadaten externer Tools** (Produktkatalog, Schaltplankonfigurator, Namensschildkonfigurator, Planungsassistent, Elbridge, 3D-Showroom usw.).

**Wichtig:** Hier wird **keine Tool-Logik** implementiert. Diese Tools bleiben außerhalb dieser Codebasis und werden ausschließlich verlinkt, über Subdomain angebunden, als Serviceportal-Kachel registriert oder in begründeten Ausnahmefällen per iframe eingebunden.

> Status: leer. Die spätere Tool-Registry ist in `src/features/serviceportal/data/toolLinks.ts` geplant. Siehe Tool-Doktrin in [`docs/architecture.md`](../../docs/architecture.md).
